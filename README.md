# 📚 Kitab Khana | Urdu Novels

**Kitab Khana** is a beautifully designed, interactive website dedicated to Urdu literature and novel lovers. It allows users to explore a collection of popular Urdu novels, discover their authors and genres, filter books by category, and join a reading circle. Built using **HTML, CSS, and JavaScript**, the project combines an elegant design with interactive features to create an enjoyable browsing experience.

## 🌐 Live Demo

Explore the live website here:  

[**Kitab Khana – Urdu Novels**](https://shumail-stack.github.io/Web-Assignment-1/)

## ✨ Features

- **Explore Urdu Novels:** Browse a collection of popular Urdu novels with their authors, genres, and ratings.
- **Genre-Based Filtering:** Filter novels by categories such as Romance, Psychological Thriller, History, Spiritual Fiction, and Pakistani Literature.
- **Interactive About Section:** Expand the About Us section using the Read More feature.
- **Light/Dark Mode:** Switch between light and dark themes.
- **Reading Circle Form:** Join the reading community by submitting personal details and reading preferences.
- **Interactive Elements:** Includes form validation, character counter, and dynamic messages.
- **Literary Destinations:** Explore cities associated with famous Urdu novels.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, responsive design, and visual appearance.
- **JavaScript** – Interactive features, filtering, theme switching, and form functionality.

## 🚀 How to Run the Project

You can view the live project directly here: 

[**Open Kitab Khana Website**](https://shumail-stack.github.io/Web-Assignment-1/)

Alternatively, to run it locally:

1. Clone or download this repository.
2. Open the project folder.
3. Double-click the `index.html` file.
4. The website will open in your default web browser.

**Note:** For the best experience, use a modern browser such as Google Chrome or Mozilla Firefox.
